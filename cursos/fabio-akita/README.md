### `hello-world-c/`

"Hello, World!" em C, do video [`oSCVb4Ts-G4`](https://youtu.be/oSCVb4Ts-G4).

```bash
cd hello-world-c
gcc hello.c -o hello && ./hello
```

O binario compilado (`hello`) e ignorado pelo git; versione apenas o `hello.c`.
