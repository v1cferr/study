# Rocketseat

Estudos acompanhando trilhas da [Rocketseat](https://www.rocketseat.com.br/).

## Trilhas

### `ai-dev/`

Introducao a IA para desenvolvedores (Python).

- `cards.py`, `data.json`: exercicios e projeto da trilha
- `teste.py`, `teste.ipynb`: experimentos
- `Pipfile`, `Pipfile.lock`: dependencias (pipenv)

#### Como rodar

```bash
cd ai-dev
pipenv install
pipenv run python cards.py
```
