# Rocketseat

Estudos acompanhando trilhas da [Rocketseat](https://www.rocketseat.com.br/).

## Trilhas

### `ai-dev/`

Introdução a IA para desenvolvedores (Python).

- `cards.py`, `data.json` — exercícios/projeto da trilha
- `teste.py`, `teste.ipynb` — experimentos
- `Pipfile` / `Pipfile.lock` — dependências (pipenv)

#### Como rodar

```bash
cd ai-dev
pipenv install
pipenv run python cards.py
```
