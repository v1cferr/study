# C# / .NET

Estudos em C# e no ecossistema .NET.

## Projetos

### `CadastroClientes/`

Web API em ASP.NET Core para cadastro de clientes.

- **Controllers/** — endpoints (`ClientesController`)
- **Models/** — entidades (`Cliente`)
- `CadastroClientes.http` — requisições de exemplo para testar a API
- `CadastroClientes.sln` — solution

#### Como rodar

```bash
cd CadastroClientes
dotnet run
```
